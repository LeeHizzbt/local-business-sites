# Local business preview sites (unofficial)
Static one-page previews for local businesses in Pikeville (41501) and Elkhorn City (41522), KY, built only from public sources. Each folder has `index.html` and `sources.md`. All pages are `noindex,nofollow` and `robots.txt` disallows crawling. The businesses have not been contacted.

Skipped (closed): Gold Ring Diner (closed; owners moved to Duckers Barn and Grill, WYMT Aug 1 2020), El Durango (251 W Russell St now listed as Acapulco Mexican Restaurant / The Sunshine Spot), Southern Biscuit & Grill (closed 2020, WYMT).
